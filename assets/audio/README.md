# Audio Assets

Optional replacement sound files can live in this folder.

Expected file names:

- `bgm-loop.ogg`
- `jump.ogg`
- `shoot.ogg`
- `hit.ogg`
- `die.ogg`

The current build uses Web Audio synthesis for bright original placeholder sounds.
If you replace them with files later, keep the paths aligned with `src/config/assets.js`.
