# Image Assets

Optional replacement art files can live in this folder.

Expected file names:

- `hero-idle.png`
- `hero-run-1.png`
- `hero-run-2.png`
- `hero-jump.png`
- `blob-walk-1.png`
- `blob-walk-2.png`

The current build draws original vector art in code, so these files are not required.
If you add them later, keep the file names aligned with `src/config/assets.js`.
